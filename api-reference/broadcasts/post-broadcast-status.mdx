## Broadcast Status API


**Endpoint:**  
POST: api/broadcast/status


## Description :
Real-time socket-style API used by the frontend to **poll / refresh broadcast or campaign progress** while the user is on the dashboard or broadcast detail screen.
- If `campaign_id` is empty/0 → **Broadcast** status.
- If `campaign_id` > 0 → **Campaign** status.


## Request Body :


### Option 1: Broadcast Status (Broadcast Only) : 
{
  "fax_uuid": "string (required)",
  "broadcast_id": 123
}


### Option 2: Campaign Status (Broadcast + Campaign) :
{
  "fax_uuid": "string (required)",
  "broadcast_id": 123,
  "campaign_id": 456
}


| Field        | Type   | Required | Description                                                                                |
|-------------|--------|----------|--------------------------------------------------------------------------------------------|
| fax_uuid    | string | Yes      | Parent fax UUID. Must exist in `faxes` and `broadcast_faxes_counts`.                      |
| broadcast_id| int    | Yes      | Broadcast ID attached to the fax.                                                         |
| campaign_id | int    | No       | When provided and > 0, API returns **campaign** status; if omitted/0, returns **broadcast** status. |
