The Call Recordings resource provides access to audio recordings captured during voice calls where recording was enabled. Recordings are scoped to a parent call — you reference them using the originating call's ID. Use this resource to list all recordings for a given call, retrieve metadata such as duration and file size, and download the raw audio file. Recordings are available shortly after a call completes.

## GET /v1/calls/{call_id}/recordings

Retrieve all recordings associated with a specific call. Most calls produce a single recording, but calls that were transferred or placed on hold may have multiple recording segments.

### Path parameters

<ParamField path="call_id" type="string" required>

</ParamField>

### Query parameters

<ParamField query="limit" type="integer">
  Number of results per page. Defaults to `20`, maximum `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from `meta.next_cursor` in the previous response.
</ParamField>

## GET /v1/calls/{call_id}/recordings/{id}/download

Download the audio file for a recording. This endpoint streams the binary audio content directly — use it to save or process the recording file.

### Path parameters

<ParamField path="call_id" type="string" required>
  The unique identifier of the parent call.
</ParamField>

<ParamField path="id" type="string" required>
  The unique identifier of the recording to download.
</ParamField>

<Info>
  The response is a binary audio stream, not a JSON object. Check the `Content-Type` response header for the audio format — typically `audio/mpeg` (MP3) or `audio/wav`. Download is only available when the recording `status` is `available`.
</Info>

<Warning>
  Recording files may be large. Stream the response to disk rather than buffering the entire file in memory, especially for long calls.
</Warning>
