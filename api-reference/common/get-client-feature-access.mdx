## Captured contract

```text
USE: Get feature access list for client.

Retrieves the list of available product features for the authenticated client along with their access permissions for each subscription plan.




The API can be used by the frontend to determine which features should be available based on the client's current plan.




Response fields:




category_type — Category/module the feature belongs to, such as Fax & Doc Exchange or eSign & Forms.
feature — Name of the feature.
basic_plan — Indicates whether the feature is available in the Basic plan.
plus_plan — Indicates whether the feature is available in the Plus plan.
pro_plan — Indicates whether the feature is available in the Pro plan.
meta.request_id — Unique request identifier for logging and troubleshooting.




Boolean values: true means the feature is included in that plan, while false means it is not available.




Example use case: When a client is on the Basic plan, the frontend can use basic_plan to determine which features are accessible and which require an upgrade.




Endpoint:

GET: api/client/feature-access
```
