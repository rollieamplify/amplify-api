## Captured contract

```text
Submits a sales inquiry for a reseller product and notifies the assigned sales representative via email.




USE: Submit a contact sales inquiry.




Request Parameters:




first_name — Customer's first name.
last_name — Customer's last name.
company_name — Customer's company name.
phone_number — Customer's contact number.
work_email — Customer's work email address.
fax_page_per_month — Estimated monthly fax pages.
product_name — Product/domain for which the inquiry is submitted.




Response: Returns a success message confirming that the sales inquiry has been submitted.




The meta object contains the request_id, which can be used for request tracking and troubleshooting.




Endpoint:

POST: api/reseller/contact-sales
```
