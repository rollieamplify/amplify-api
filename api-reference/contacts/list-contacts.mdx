---
title: "List contacts"
description: "Retrieve a paginated list of contacts."
api: "GET /contacts"
public: true
---

<ParamField header="access_token" type="string" required>API access token.</ParamField>
<ParamField query="limit" type="integer" default="20">Results per page, from `1` to `100`.</ParamField>
<ParamField query="cursor" type="string">Cursor returned by a previous response.</ParamField>
<ParamField query="search_value" type="string">Search text for matching contacts.</ParamField>
<ParamField query="type" type="integer">Contact type: `0` individual, `1` organization, or `2` patient.</ParamField>

```bash
curl 'https://api.amplify.xyz/v1/contacts?limit=20&type=0' \
  --header 'access_token: YOUR_ACCESS_TOKEN'
```

The response contains contact records and a `meta` object with pagination data and `request_id`.
