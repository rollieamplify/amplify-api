The Contacts API provides public endpoints for individual, organization, and patient contacts. All requests use the Amplify API base URL:

```text
https://api.amplify.xyz/v1
```

## Authentication

Send your API access token in the `access_token` request header unless an endpoint explicitly states otherwise.

```bash
curl --request GET \
  --url 'https://api.amplify.xyz/v1/contacts' \
  --header 'access_token: YOUR_ACCESS_TOKEN'
```

## Contact types

| Value | Type |
| --- | --- |
| `0` | Individual |
| `1` | Organization |
| `2` | Patient |

Dates and timestamps in responses use ISO 8601 UTC format.
