The Conversations resource groups related SMS and MMS messages into threads organized by participant phone numbers. Amplify automatically creates or updates a conversation whenever a message is sent or received between the same set of numbers. Use this resource to list all conversations, inspect thread metadata, and retrieve the ordered message history within a specific conversation.

## GET /v1/conversations

Retrieve a paginated list of all conversations on your account, ordered by most recent message activity.

### Query parameters

<ParamField query="limit" type="integer">
  Number of results per page. Defaults to `20`, maximum `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from `meta.next_cursor` in the previous response.
</ParamField>

<ParamField query="phone_number" type="string">
  Filter conversations that include this phone number (E.164 format) as a participant.
</ParamField>

### Code example

```bash cURL
curl https://api.amplify.xyz/v1/conversations \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## GET /v1/conversations/{id}

Retrieve the details and current state of a single conversation by its ID.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the conversation.
</ParamField>

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the conversation, prefixed with `conv_`.
</ResponseField>

<ResponseField name="participants" type="array">
  Array of phone numbers in E.164 format that are part of this conversation thread.
</ResponseField>

<ResponseField name="last_message_at" type="string">
  ISO 8601 timestamp of the most recent message in this conversation.
</ResponseField>

<ResponseField name="message_count" type="integer">
  Total number of messages (inbound and outbound) in this conversation.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when this conversation was first created.
</ResponseField>

### Example response

```json
{
  "data": {
    "id": "conv_01HZA3NKPQR5T8CWOX4Q7ZJDE",
    "participants": [
      "+18005550199",
      "+14155550100"
    ],
    "last_message_at": "2024-06-01T13:00:00Z",
    "message_count": 7,
    "created_at": "2024-05-15T09:30:00Z"
  }
}
```

## GET /v1/conversations/{id}/messages

Retrieve a paginated, chronologically ordered list of messages within a specific conversation.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the conversation.
</ParamField>

### Query parameters

<ParamField query="limit" type="integer">
  Number of messages per page. Defaults to `20`, maximum `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from `meta.next_cursor` in the previous response.
</ParamField>

<ParamField query="order" type="string">
  Sort order for messages. Use `asc` for oldest-first or `desc` for newest-first. Defaults to `asc`.
</ParamField>

### Response

Returns a paginated array of message objects. Each object has the same shape as the response from `GET /v1/messages/{id}`. See [Messages](/api-reference/messages) for the full field reference.

```json
{
  "data": [
    {
      "id": "msg_01HZA3NKPQR5T8CWOX4Q7ZJDF",
      "status": "delivered",
      "to": "+14155550100",
      "from": "+18005550199",
      "body": "Your appointment is confirmed for tomorrow at 10am.",
      "direction": "outbound",
      "conversation_id": "conv_01HZA3NKPQR5T8CWOX4Q7ZJDE",
      "created_at": "2024-06-01T13:00:00Z"
    }
  ],
  "meta": {
    "total": 7,
    "next_cursor": null
  }
}
```

<Info>
  Messages returned from this endpoint are identical in structure to those from the `/v1/messages` resource. You can use either endpoint to access message data — this endpoint is simply scoped to a single conversation for convenience.
</Info>
