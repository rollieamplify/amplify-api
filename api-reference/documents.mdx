The Documents resource lets you upload, manage, and retrieve document files stored in Amplify. You can upload a file directly using a multipart form request or provide a `document_url` for Amplify to fetch and store remotely. Optionally organize documents into [Folders](/api-reference/folders) by providing a `folder_id`. Documents stored here can also be referenced in other resources, such as the [Faxes](/api-reference/faxes) and [eSign Documents](/api-reference/esign-documents) APIs.

## POST /v1/documents

Upload a new document. Use multipart form data to upload a file directly, or provide a `document_url` to have Amplify fetch and store the file from a remote location.

### Request body

<ParamField body="file" type="file">
  The document file to upload, sent as a `multipart/form-data` field. Required if `document_url` is not provided. Supported formats include PDF, DOCX, XLSX, PPTX, JPEG, PNG, and TIFF.
</ParamField>

<ParamField body="document_url" type="string">
  Publicly accessible URL of a document to fetch and store. Required if `file` is not provided.
</ParamField>

<ParamField body="name" type="string">
  Display name for the document. If omitted, Amplify uses the original filename or the last path segment of `document_url`.
</ParamField>

<ParamField body="folder_id" type="string">
  ID of the folder to place this document in. If omitted, the document is stored at the root level.
</ParamField>

### Code examples

<CodeGroup>

```bash cURL (file upload)
curl -X POST https://api.amplify.xyz/v1/documents \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@/path/to/invoice.pdf" \
  -F "name=Invoice June 2024" \
  -F "folder_id=fld_01HZF9KMPQS3T6BVOW4R7YJCE"
```

```bash cURL (URL import)
curl -X POST https://api.amplify.xyz/v1/documents \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "document_url": "https://example.com/report.pdf",
    "name": "Q2 Report",
    "folder_id": "fld_01HZF9KMPQS3T6BVOW4R7YJCE"
  }'
```

</CodeGroup>

## GET /v1/documents

Retrieve a paginated list of documents on your account.

## GET /v1/documents/{id}

Retrieve full metadata for a single document by its ID.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the document.
</ParamField>

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the document, prefixed with `doc_`.
</ResponseField>

<ResponseField name="name" type="string">
  Display name of the document.
</ResponseField>

<ResponseField name="size" type="integer">
  File size in bytes.
</ResponseField>

<ResponseField name="mime_type" type="string">
  MIME type of the document (e.g., `application/pdf`, `image/jpeg`).
</ResponseField>

<ResponseField name="folder_id" type="string">
  ID of the folder containing this document. `null` if the document is at the root level.
</ResponseField>

<ResponseField name="created_at" type="string">

</ResponseField>

## DELETE /v1/documents/{id}

Permanently delete a document and its stored file. This action cannot be undone.

<Warning>
  Deleting a document removes the file from storage. Any faxes, eSign envelopes, or forms that referenced this document may be affected. Download the file before deleting if you need to retain a copy.
</Warning>

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the document to delete.
</ParamField>
