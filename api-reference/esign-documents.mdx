The eSign Documents resource lets you send documents to one or more recipients for electronic signature, monitor each signer's progress in real time, and download the final signed document once all parties have completed it. You can supply either a `document_url` pointing to an existing file or a `template_id` to use a pre-configured signature template. Recipients receive an email with a secure link to review and sign the document.

## POST /v1/esign/documents

Send a document envelope to one or more recipients for electronic signature. Amplify emails each recipient a secure signing link immediately after the request succeeds. Track progress by polling `GET /v1/esign/documents/{id}` or subscribing to `esign.completed` and `esign.declined` webhook events.

### Request body

<ParamField body="document_url" type="string">
  Publicly accessible URL of the document to send for signature. Supported formats include PDF and DOCX. Required if `template_id` is not provided.
</ParamField>

<ParamField body="template_id" type="string">
  ID of an existing eSign template to use. Required if `document_url` is not provided. See [eSign Templates](/api-reference/esign-templates).
</ParamField>

<ParamField body="recipients" type="array" required>
  Ordered list of signers. Each recipient is assigned a role and receives a signing invitation.

  <Expandable title="Recipient fields">
    <ParamField body="recipients[].name" type="string" required>
      Full name of the recipient.
    </ParamField>
    <ParamField body="recipients[].email" type="string" required>
      Email address of the recipient. Signing invitations are sent here.
    </ParamField>
    <ParamField body="recipients[].role" type="string">
      Role identifier matching a role defined in the template or document. Required when using a `template_id`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="subject" type="string">
  Subject line of the signing invitation email. Defaults to a standard Amplify subject if omitted.
</ParamField>

<ParamField body="message" type="string">
  Custom message body included in the signing invitation email.
</ParamField>

## GET /v1/esign/documents

## GET /v1/esign/documents/{id}

Retrieve the full details and per-recipient signing status for a single eSign document envelope.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the eSign document.
</ParamField>

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the document envelope, prefixed with `esign_`.

<ResponseField name="status" type="string">

</ResponseField>

<ResponseField name="recipients" type="array">

## DELETE /v1/esign/documents/{id}

Cancel a pending or in-progress eSign document envelope. Cancellation notifies recipients that the envelope has been withdrawn. Completed or already-cancelled envelopes cannot be cancelled.

<Warning>
  Cancelling an envelope is irreversible. If you need the document signed, create a new envelope.
</Warning>

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the eSign document to cancel.
</ParamField>

## GET /v1/esign/documents/{id}/download

Download the fully signed document as a PDF. This endpoint is only available after the envelope `status` is `completed`.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the completed eSign document to download.
</ParamField>

<Info>
  The response is a binary PDF stream (`Content-Type: application/pdf`). Attempting to download a document that is not yet in `completed` status returns a `409 Conflict` error.
</Info>
