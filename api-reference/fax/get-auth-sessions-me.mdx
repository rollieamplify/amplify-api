Description

Retrieves the authenticated user's session information, including profile details, account information, roles, permissions, and application-specific settings required to initialize the user session after login.




This endpoint also returns CloudFront signed cookies in the response headers (CloudFront-Policy, CloudFront-Signature, and CloudFront-Key-Pair-Id). These cookies are required to securely access private documents and files served through CloudFront. The browser stores these cookies automatically and includes them in subsequent requests to protected CloudFront resources.




Authentication: Required (Bearer Token)




Response Includes:

User profile details
Account information
User permissions and access controls
Timezone and application settings
Session-related metadata
CloudFront signed cookies (via Set-Cookie response headers)

Note:
The frontend should make this request with withCredentials: true to allow the browser to store the CloudFront signed cookies. If the cookies expire, the frontend can call GET /api/cloud-front/refresh-cookie to obtain a new set of signed cookies without requiring the user to authenticate again.

GET : api/auth/sessions/me
