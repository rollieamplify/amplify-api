## Captured contract

```text
Check User Exists




Endpoint: GET /api/auth/users/exists




Description: Checks if an email exists for login/signup. Supports reseller portal (product_name), work-email check (check_work_email), SSO, and restricted domain.

Request

Param

	

Type

	

Required

	

Description




email

	

string

	

Yes

	

User email




product_name

	

string

	

No

	

Reseller default_domain (empty = main Amplify)




check_work_email

	

boolean

	

No

	

Validate work email when true




Example:




GET /api/auth/users/exists?email=user@example.com
GET /api/auth/users/exists?email=client@example.com&product_name=reseller.example.com
GET /api/auth/users/exists?email=user@company.com&check_work_email=1
Response — Email exists (200)
{
  "data": {
    "exists": true,
    "login_by": "credentials",
    "message": "",
    "app_access_web_mobile": true
  },
  "meta": {
    "request_id": "uuid-string"
  }
}
Response — Email does not exist (200)
{
  "data": {
    "exists": false,
    "login_by": "credentials",
    "message": "",
    "app_access_web_mobile": false
  },
  "meta": {
    "request_id": "uuid-string"
  }
}
Response — OAuth account (200)
{
  "data": {
    "exists": true,
    "login_by": "google",
    "message": "This email address is associated with a Google account. Login with Google or reset your password to log in manually.",
    "app_access_web_mobile": true
  },
  "meta": {
    "request_id": "uuid-string"
  }
}
```
