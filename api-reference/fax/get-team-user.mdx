# List Sub-Users API

**Endpoint:**  

GET: api/team-user

# Description :

Returns a paginated list of sub-users (team users) for the authenticated account. Each sub-user includes profile fields and `user_permissions` grouped by category (Product, General, iFax, Call, eSign, Forms).

# Query Parameters :

| Parameter | Type | Default | Description |

|-----------|------|---------|-------------|

| cursor | int | 1 | Page number (1-based). |

| limit | int | 20 | Items per page (1–200). |




**Example:** 

 `GET api/team-user?cursor=1&limit=20`

None
