# Multi Assign User API


**Endpoint:**  
POST: api/fax/multi_assigned_user


# Description :
Assigns multiple inbound faxes to multiple users in one request. Uses the `assigned_faxes` table to store mappings. Only inbound faxes (type = 2) are processed; invalid faxes, invalid users, and already-existing (fax_uuid + user_id) pairs are skipped. User IDs are restricted to those belonging to the logged-in user (primary/client: any user in the account; sub-user: only themselves).  
Expects `fax_uuids` (array of fax UUID strings) and `user_ids` (array of user IDs).


# Request Body :
{
  "fax_uuids": ["abc-123-uuid-1", "abc-123-uuid-2"],
  "user_ids": [1, 2],
  "role_ids": [1, 2]
}


| Field        | Type    | Required | Description                                                                 |
|--------------|---------|----------|-----------------------------------------------------------------------------|
| fax_uuids    | array   | Yes      | List of inbound fax UUIDs (strings).                                        |
| fax_uuids.*  | string  | Yes      | Inbound fax UUID (must exist, belong to account, and be type = inbound).    |
| user_ids     | array   | Yes      | List of user IDs (integers) to assign to.                                    |
| user_ids.*   | integer | Yes      | User ID (must belong to the account and to the logged-in user’s scope).          |


# Response Format :


## Success Response (HTTP 200) :

  "data": {

        ]

      {
        "user_id": 2,
        "socket_ids": []
      }

  },

  }
}
