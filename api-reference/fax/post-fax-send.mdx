validate_duplicate_fax
- If the user wants to enable duplicate fax validation for a specific fax, they must pass the value as true.
When true, the system will check for duplicate faxes.
When false, duplicate fax validation will be bypassed for the current fax.
disabled_check_duplicate_fax
-  If the user wants to permanently disable duplicate fax validation, they must set this value to "true"
-  When set to true, the system will disable duplicate fax validation for all future fax requests. 


Duplicate fax error response (same fax within 24 hours):

    }
}
