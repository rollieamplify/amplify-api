## Captured contract

```text
# Save As Fax Default API


## Overview
This API endpoint allows you to save documents as fax defaults by providing URLs. The system will download the files from the provided URLs, upload them to S3, generate thumbnails, and return the document information.


## Endpoint :
POST /api/fax_templates/save_as_fax_default


## Request
### Request Body :
{
  "url": [
    {
      "url": "https://example.com/document.pdf",
      "file_name": "document.pdf",
      "is_smart_document": 0
    }
  ]
}


### Request Parameters :


| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `url` | array | Yes | Array of URL objects containing document information |
| `url[].url` | string (URL) | Yes | The URL of the document to download |
| `url[].file_name` | string | No | Optional filename for the document. If not provided, it will be extracted from the URL |
| `url[].is_smart_document` | integer | No | Flag to indicate if this is a smart document (0 or 1). Default: 0 |


### Example Request :


#### Single Document :
{
  "url": [
    {
      "url": "https://example.com/sample-document.pdf",
      "file_name": "sample-document.pdf",
      "is_smart_document": 0
    }
  ]
}


#### Multiple Documents : 
{
  "url": [
    {
      "url": "https://example.com/document1.pdf",
      "file_name": "document1.pdf",
      "is_smart_document": 0
    },
    {
      "url": "https://example.com/document2.pdf",
      "file_name": "document2.pdf",
      "is_smart_document": 1
    }
  ]
}


#### Without File Name (Auto-extracted) : 
{
  "url": [
    {
      "url": "https://example.com/files/my-document.pdf",
      "is_smart_document": 0
    }
  ]
}
```
