Transmission Receipt API.

EndPoint:
POST: api/fax/transmission/receipt

Body:
{
  "fax_uuid": "01KFD10X4YY30Q2CPTD41M5WDW",
  "include_attachment": true,
  "pages": "all"
}


{
  "broadcast_fax_uuid": "01KG6KMHWE6HMZAMYNCFJAAVYH",
  "include_attachment": true,
  "pages": "all"
}


NOTE:

fax_uuid → used for fax
broadcast_fax_uuid → used for broadcast

include_attachment
true  → include fax attachment pages with receipt
false → return receipt PDF only

pages
REQUIRED ONLY when include_attachment = true
1    → receipt + first attachment page only
all  → receipt + all attachment pages

{
