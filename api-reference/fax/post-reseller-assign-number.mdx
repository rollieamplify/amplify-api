## Captured contract

```text
Assign / Unassign Client Number




Endpoint




POST /api/reseller/assign-number




Description




Assigns a fax number to a client. If the number is already assigned to another client, the previous assignment is replaced. To unassign a number, omit the client_id or pass it as null.

Request Body

Field

	

Type

	

Required

	

Description




number_id

	

Integer

	

Yes

	

ID of the fax number to assign or unassign.




client_id

	

Integer | Null

	

No

	

Client user ID. If omitted or null, the number is unassigned.

Assign Number
{
    "number_id": 15,
    "client_id": 1024
}
Unassign Number
{
    "number_id": 15,
    "client_id": null
}




or




{
    "number_id": 15
}
```
