## Captured contract

```text
# Get Reseller by Product Name API

**Endpoint:**  

POST: api/reseller/details

# Description :

Fetches reseller branding details by product name (default domain). Used when the frontend needs to load reseller/whitelabel configuration (logos, colors, product name) for a given domain or product identifier.  

Expects `product_name` (the reseller’s default domain or product name).


# Request Body :

{
  "product_name": "example.ifaxapp.com"
}

| Field        | Type   | Required | Description                                      |

|-------------|--------|----------|--------------------------------------------------|

| product_name | string | Yes      | Reseller’s default domain or product name (max 255). |

# Response Format :
```
