# Bulk Create Sub-Users API

**Endpoint:**  

POST: api/team-user/bulk_store

# Description :

Creates multiple sub-users in one request. `first_name`, `last_name`, and `email` are comma-separated lists; the number of values in each must match. The same `user_permissions` (and optional `role_id`) are applied to all created users. Invitation emails are sent when `need_password` is 0.

# Request Body :

 {
  "first_name": "John, Jane, Bob",
  "last_name": "Smith, Doe, Wilson",
  "email": "john@example.com,jane@example.com,bob@example.com",
  "need_password": 0,
  "role_id": "2",
  "user_note": "user1, user3",
  "license_type": 1,
  "user_permissions": {
    "access_ifax": true,
    "send_faxes": true
  },
    "user_notifications": [
        {
            "key": "transmission_started_accessible_number_client",
            "product": "fax",
            "category": "inbound_fax",
            "type": "email",
            "settings": {
                "attach_certificate": false,
                "include_audit_trail": false,
                "attach_pdf": true,
                "show_open_link": false
            }
        }
    ]
}

| Field | Type | Required | Description |

|-------|------|----------|-------------|

| first_name | string | Yes | Comma-separated names; count must match email count. |

| last_name | string | Yes | Comma-separated; count must match. |

| email | string | Yes | Comma-separated emails; each must be unique. |

| need_password | int | Yes | `0` or `1`. |

| role_id | int | No | Optional. |

| user_permissions | object | Yes | Same format as Create; applied to all users. |
