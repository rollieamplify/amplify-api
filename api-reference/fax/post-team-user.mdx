# Create Sub-User API

**Endpoint:**  

POST: api/team-user

# Description :

Creates a new sub-user (team user) for the authenticated account. You must provide either `role_id` (to assign a role) or `user_permissions` (custom permissions), but not both.

- **need_password = 1:** A password is generated and returned in the response.

- **need_password = 0:** An invitation email is sent; `invitation_link` is included when status is pending.

# Request Body :

## Option 1: Create with Role :

{
  "first_name": "John",
  "last_name": "Smith",
  "email": "john@example.com",
  "need_password": 0,
  "job_title": "Support",
  "role_id": 2,
  "user_note": "dummy"
}

| job_title | string | No | Must exist in `job_titles` if provided. |

| role_id | int | Conditional | Either `role_id` or `user_permissions` required, not both. |

| user_permissions | object | Conditional | Custom permissions. Keys = permission keys from PermissionSeeder; values = `true`/`false`, `"all_documents"`/`"assigned_documents"`, or comma-separated IDs. |
