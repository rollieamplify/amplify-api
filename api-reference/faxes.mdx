The Faxes resource lets you send outbound faxes by providing a destination number and a document URL, list both inbound and outbound faxes associated with your account, retrieve the current delivery status of any fax, and download the underlying fax document. Fax numbers must be provided in E.164 format (for example, `+14155550100`).

## POST /v1/faxes

Send a fax to the specified destination number. Amplify retrieves the document from `document_url`, converts it if needed, and queues it for transmission. Monitor delivery by polling `GET /v1/faxes/{id}` or by listening for the `fax.delivered` and `fax.failed` webhook events.

### Request body

<ParamField body="to" type="string" required>
  Destination fax number in E.164 format (e.g., `+14155550100`).
</ParamField>

<ParamField body="from" type="string" required>
  Sender fax number in E.164 format. Must be a fax-capable number provisioned on your Amplify account.
</ParamField>

<ParamField body="document_url" type="string" required>
  Publicly accessible URL of the document to fax. Supported formats include PDF, TIFF, and DOCX. The URL must be reachable by Amplify's servers at the time of sending.
</ParamField>

<ParamField body="quality" type="string">
  Transmission quality level. One of `standard`, `fine`, or `superfine`. Defaults to `standard`. Higher quality increases transmission time.
</ParamField>

### Code examples

<CodeGroup>

```bash cURL
curl -X POST https://api.amplify.xyz/v1/faxes \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+14155550100",
    "from": "+18005550199",
    "document_url": "https://example.com/invoice.pdf",
    "quality": "fine"
  }'
```


## GET /v1/faxes

Retrieve a paginated list of faxes. Use query parameters to filter by direction, status, or date range.

### Query parameters

<ParamField query="limit" type="integer">
  Number of results per page. Defaults to `20`, maximum `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor returned in `meta.next_cursor` from the previous response.
</ParamField>

<ParamField query="direction" type="string">
  Filter by `inbound` or `outbound`.
</ParamField>

<ParamField query="status" type="string">
  Filter by fax status. One of `queued`, `sending`, `delivered`, `failed`, or `received`.
</ParamField>

## DELETE /v1/faxes/{id}

Cancel a queued or in-progress fax, or delete the record of a completed fax. Cancellation is only possible while the fax has a status of `queued`.

<Warning>
  Deleting a fax record is permanent and also removes access to any associated downloadable document. Download the document first if you need to retain it.
</Warning>

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the fax to cancel or delete.
</ParamField>

## GET /v1/faxes/{id}/download

Download the fax document as a file. For outbound faxes this returns the document you submitted; for inbound faxes it returns the received document.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the fax whose document you want to download.
</ParamField>

<Tip>
  The response is a binary file stream, not a JSON object. Inspect the `Content-Type` response header to determine the file format (commonly `application/pdf` or `image/tiff`).
</Tip>
