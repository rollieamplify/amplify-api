The Folders resource lets you create a hierarchical folder structure to organize documents stored in Amplify. Each folder can have a parent folder, enabling nested directory trees. Assign documents to a folder by providing its `id` as the `folder_id` when uploading or updating a document via the [Documents](/api-reference/documents) API. Deleting a folder does not automatically delete its contents — move or delete documents within it first.

## POST /v1/folders

Create a new folder. Optionally nest it under an existing folder by providing a `parent_folder_id`.

### Request body

<ParamField body="name" type="string" required>
  Display name of the folder.
</ParamField>

<ParamField body="parent_folder_id" type="string">
  ID of the parent folder. Omit or pass `null` to create a root-level folder.
</ParamField>

### Code example

```bash cURL
curl -X POST https://api.amplify.xyz/v1/folders \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Client Contracts",
    "parent_folder_id": null
  }'
```

## GET /v1/folders

Retrieve a paginated list of folders on your account.

### Query parameters

<ParamField query="limit" type="integer">
  Number of results per page. Defaults to `20`, maximum `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from `meta.next_cursor` in the previous response.
</ParamField>

<ParamField query="parent_folder_id" type="string">
  Return only folders that are direct children of this parent folder. Use `root` to list top-level folders.
</ParamField>

## GET /v1/folders/{id}

Retrieve full details for a single folder by its ID, including its document count.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the folder.
</ParamField>

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the folder, prefixed with `fld_`.
</ResponseField>

<ResponseField name="name" type="string">
  Display name of the folder.
</ResponseField>

<ResponseField name="parent_folder_id" type="string">
  ID of the parent folder. `null` if this is a root-level folder.
</ResponseField>

<ResponseField name="document_count" type="integer">
  Number of documents directly inside this folder (does not include documents in subfolders).
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the folder was created.
</ResponseField>

### Example response

```json

    "name": "Client Contracts",
    "parent_folder_id": null,
    "document_count": 12,
    "created_at": "2024-05-01T08:00:00Z"
  }
}
```

## DELETE /v1/folders/{id}

Delete a folder. The folder must be empty before it can be deleted — move or delete all documents and subfolders within it first.

<Warning>
  This operation cannot be undone. Attempting to delete a non-empty folder returns a `409 Conflict` error. Remove all contents before deleting the folder.
</Warning>

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the folder to delete.
</ParamField>
