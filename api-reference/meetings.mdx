The Meetings resource provides access to video and audio meetings scheduled or hosted through Amplify. Use it to list upcoming and past meetings on your account and to retrieve full details for a specific meeting, including scheduled time, participants, and any associated recording links. Full creation and management endpoints are defined in the OpenAPI specification and will be reflected here when published.

</Note>

## GET /v1/meetings

Retrieve a paginated list of meetings on your account, ordered by scheduled start time.

### Query parameters

<ParamField query="limit" type="integer">
  Number of results per page. Defaults to `20`, maximum `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from `meta.next_cursor` in the previous response.
</ParamField>

<ParamField query="status" type="string">
  Filter by meeting status. Expected values include `scheduled`, `in-progress`, and `completed`.
</ParamField>

### Code examples

<CodeGroup>

```bash cURL
curl https://api.amplify.xyz/v1/meetings \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript Node.js
const response = await fetch("https://api.amplify.xyz/v1/meetings", {
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
  },
});

const { data, meta } = await response.json();
console.log(data.length, "meeting(s) found");
```

</CodeGroup>

## GET /v1/meetings/{id}

Retrieve the full details for a single meeting by its ID.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the meeting.
</ParamField>

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the meeting, prefixed with `mtg_`.
</ResponseField>

<ResponseField name="title" type="string">
  Display name or subject of the meeting.
</ResponseField>

<ResponseField name="status" type="string">
  Current status. One of `scheduled`, `in-progress`, or `completed`.
</ResponseField>

<ResponseField name="scheduled_at" type="string">
  ISO 8601 timestamp of the meeting's planned start time.
</ResponseField>

<ResponseField name="duration" type="integer">
  Duration of the meeting in minutes. `null` if not yet completed.
</ResponseField>

<ResponseField name="participants" type="array">
  Array of participant objects.

  <Expandable title="Participant fields">
    <ResponseField name="participants[].name" type="string">
      Display name of the participant.
    </ResponseField>
    <ResponseField name="participants[].email" type="string">
      Email address of the participant.
    </ResponseField>
    <ResponseField name="participants[].joined_at" type="string">
      ISO 8601 timestamp of when the participant joined. `null` if they have not yet joined.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="recording_url" type="string">
  URL to access the meeting recording, if recording was enabled and the meeting has completed. `null` otherwise.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the meeting was created.
</ResponseField>
