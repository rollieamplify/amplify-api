The Messages resource lets you send SMS and MMS messages from Amplify-provisioned numbers, retrieve individual message records, and list message history filtered by status, direction, or date. To send an MMS, include a `media_url` in your request. Optionally associate a message with an existing conversation by providing a `conversation_id`.

## POST /v1/messages

Send an outbound SMS or MMS message. Include `media_url` to send an MMS; omit it for a plain SMS. Amplify queues the message immediately and delivers it through the carrier network. Track delivery by polling `GET /v1/messages/{id}` or subscribing to `message.delivered` and `message.failed` webhook events.

### Request body

<ParamField body="to" type="string" required>
  Destination phone number in E.164 format (e.g., `+14155550100`).
</ParamField>

<ParamField body="from" type="string" required>
  Sender phone number in E.164 format. Must be a messaging-capable number provisioned on your Amplify account.
</ParamField>

<ParamField body="body" type="string" required>
  The text content of the message. Maximum 1600 characters. Long messages are automatically split into concatenated SMS segments.
</ParamField>

<ParamField body="media_url" type="string">
  Publicly accessible URL of a media file to attach (MMS). Supported types include JPEG, PNG, GIF, and MP4. When provided, the message is sent as MMS.
</ParamField>

<ParamField body="conversation_id" type="string">
  ID of an existing conversation to associate this message with. When omitted, Amplify automatically finds or creates a matching conversation thread.
</ParamField>

### Code example

```bash cURL
curl -X POST https://api.amplify.xyz/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+14155550100",
    "from": "+18005550199",
    "body": "Your appointment is confirmed for tomorrow at 10am."
  }'
```

## GET /v1/messages

Retrieve a paginated list of messages. Filter by direction, status, phone number, or conversation.

### Query parameters

<ParamField query="limit" type="integer">
  Number of results per page. Defaults to `20`, maximum `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from `meta.next_cursor` in the previous response.
</ParamField>

<ParamField query="direction" type="string">
  Filter by `inbound` or `outbound`.
</ParamField>

<ParamField query="status" type="string">
  Filter by message status.
</ParamField>

<ParamField query="conversation_id" type="string">
  Return only messages belonging to this conversation.
</ParamField>

## GET /v1/messages/{id}

Retrieve the full record for a single message by its ID.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the message.
</ParamField>

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the message, prefixed with `msg_`.
</ResponseField>

<ResponseField name="status" type="string">
  Current delivery status. One of `queued`, `sent`, `delivered`, `failed`, or `received`.
</ResponseField>

<ResponseField name="to" type="string">
  Destination phone number in E.164 format.
</ResponseField>

<ResponseField name="from" type="string">
  Sender phone number in E.164 format.
</ResponseField>

<ResponseField name="body" type="string">
  Text content of the message.
</ResponseField>

<ResponseField name="media_url" type="string">
  URL of the attached media file, if this was an MMS message. `null` for SMS messages.
</ResponseField>

<ResponseField name="direction" type="string">
  Whether this message was `inbound` or `outbound`.
</ResponseField>

<ResponseField name="conversation_id" type="string">
  ID of the conversation this message belongs to.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the message was created or received.
</ResponseField>
