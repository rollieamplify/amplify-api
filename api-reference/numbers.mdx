The Numbers resource provides access to the phone numbers provisioned on your Amplify account. Each number has a set of capabilities — such as SMS, voice, or fax — and configuration settings that control how inbound traffic is handled. Use this resource to list all your numbers, inspect their properties, and update routing or labeling settings. Number provisioning is managed through the Amplify dashboard.

<Note>
  The full interactive reference for this resource is generated from the Amplify OpenAPI spec. The endpoints and parameters below reflect the current public API surface.
</Note>

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/numbers` | List numbers |
| `GET` | `/v1/numbers/{id}` | Get a number |
| `PATCH` | `/v1/numbers/{id}` | Update number settings |

---

## GET /v1/numbers

Retrieve a paginated list of all phone numbers provisioned on your Amplify account.

### Query parameters

<ParamField query="limit" type="integer">
  Number of results per page. Defaults to `20`, maximum `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from `meta.next_cursor` in the previous response.
</ParamField>

<ParamField query="type" type="string">
  Filter by number type. One of `local`, `toll-free`, or `fax`.
</ParamField>

<ParamField query="capability" type="string">
  Filter to numbers that support a specific capability. One of `sms`, `mms`, `voice`, or `fax`.
</ParamField>

### Code example

<CodeGroup>

```bash cURL
curl https://api.amplify.xyz/v1/numbers \
  -H "access_token: YOUR_API_KEY"
```

```javascript Node.js
const response = await fetch("https://api.amplify.xyz/v1/numbers", {
  headers: { "access_token": "YOUR_ACCESS_TOKEN" },
});

const { data } = await response.json();
console.log(data); // Array of number objects
```

</CodeGroup>

## GET /v1/numbers/{id}

Retrieve the full configuration and capabilities for a single phone number.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the phone number.
</ParamField>

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the number, prefixed with `num_`.
</ResponseField>

<ResponseField name="number" type="string">
  The phone number in E.164 format (e.g., `+18005550199`).
</ResponseField>

<ResponseField name="type" type="string">
  Number type. One of `local`, `toll-free`, or `fax`.
</ResponseField>

<ResponseField name="capabilities" type="array">
  Array of strings listing the capabilities enabled on this number. Possible values include `sms`, `mms`, `voice`, and `fax`.
</ResponseField>

<ResponseField name="label" type="string">
  Optional human-readable label assigned to this number for internal identification.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the number was provisioned on your account.
</ResponseField>

### Example response

```json
{
  "data": {
    "id": "num_01HZHD9MXRS4T7BVPW5R8ZKGF",
    "number": "+18005550199",
    "type": "toll-free",
    "capabilities": ["sms", "mms", "voice"],
    "label": "Main Support Line",
    "created_at": "2024-01-15T08:00:00Z"
  }
}
```

## PATCH /v1/numbers/{id}

Update configuration settings for a phone number, such as its label or routing behavior.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the phone number to update.
</ParamField>

### Request body

<ParamField body="label" type="string">
  Human-readable label for internal identification of this number.
</ParamField>

<ParamField body="webhook_url" type="string">
  HTTPS URL to receive inbound message and call webhook events for this number. Overrides the account-level default if set.
</ParamField>

### Code example

<CodeGroup>

```bash cURL
curl -X PATCH https://api.amplify.xyz/v1/numbers/num_01HZHD9MXRS4T7BVPW5R8ZKGF \
  -H "access_token: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "label": "Sales Hotline",
    "webhook_url": "https://example.com/webhooks/inbound"
  }'
```

```javascript Node.js
const response = await fetch(
  "https://api.amplify.xyz/v1/numbers/num_01HZHD9MXRS4T7BVPW5R8ZKGF",
  {
    method: "PATCH",
    headers: {
      "access_token": "YOUR_ACCESS_TOKEN",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      label: "Sales Hotline",
      webhook_url: "https://example.com/webhooks/inbound",
    }),
  }
);

const { data } = await response.json();
console.log(data.label); // "Sales Hotline"
```

</CodeGroup>
