---
title: "List numbers"
description: "Retrieve the phone numbers available to the authenticated Amplify account."
api: "GET /numbers"
public: true
---

`GET /numbers` returns the phone numbers available to the authenticated account.

```bash
curl "https://api.amplify.xyz/v1/numbers" \
  --header "access_token: $AMPLIFY_ACCESS_TOKEN" \
  --header "Accept: application/json"
```

## Query parameters

| Parameter | Type | Required | Options | Description |
| --- | --- | --- | --- | --- |
| `type` | string | No | `fax`, `voice` | Filters numbers by type. |
| `search_string` | string | No | — | Searches both the phone number and its label. |

```bash
curl "https://api.amplify.xyz/v1/numbers?type=voice&search_string=12" \
  --header "access_token: $AMPLIFY_ACCESS_TOKEN" \
  --header "Accept: application/json"
```

## Number fields

| Field | Type | Description |
| --- | --- | --- |
| `id` | integer | Unique number identifier. |
| `number` | string | Phone number in international format. |
| `country_code` | string | Two-letter country code. |
| `country_prefix` | integer | International calling prefix. |
| `area_code` | string | Geographic area code when available. |
| `area_prefix` | string | Numeric area prefix when available. |
| `company_id` | integer or null | Associated company identifier. |
| `company_title` | string or null | Associated company name. |
| `source` | string | How the number was added, such as `purchase`. |
| `port_request_id` | string | Related port request identifier when applicable. |
| `label` | string | User-defined number label. |
| `icon` | string | User-selected icon. |
| `status` | string | Current number status, such as `active`. |
| `is_deleted` | boolean | Whether the number is deleted. |
| `access` | array | Access records associated with the number. |
| `features` | array of strings | Enabled capabilities, such as `sms`, `mms`, `fax`, `voice`, or `recording`. |
| `created_by` | integer | Identifier of the user who added the number. |
| `created_at` | string | Creation time in ISO 8601 UTC. |
| `updated_at` | string | Most recent update time in ISO 8601 UTC. |
| `ported_out_at` | string | Port-out time when applicable. |
| `type` | string | Number type, such as `fax` or `voice`. |
| `telnyx` | object | Provider-specific credentials. Treat this object as sensitive and do not log it. |
| `is_selected` | boolean | Whether the number is currently selected. |
| `is_did_verified` | integer | DID verification state. See the mapping below. |
| `is_access` | boolean | Whether the authenticated user has access. |
| `is_blocked` | boolean | Whether the number is blocked. |
| `unread_count` | integer | Number of unread items associated with the number. |
| `did_requirements` | array | Outstanding DID verification requirements. |
| `assign_permissions` | boolean | Whether the authenticated user can assign permissions. |
| `schedule` | array | Schedule configuration associated with the number. |
| `configuration` | object | Fax, voice, messaging, recording, voicemail, and user-assignment configuration. |

## DID verification states

| Value | Meaning |
| --- | --- |
| `0` | Verification pending |
| `1` | Verification completed |
| `2` | Verification in progress |

## Metadata fields

| Field | Type | Description |
| --- | --- | --- |
| `total` | integer | Total number of matching records. |
| `next_cursor` | string | Cursor for the next page. An empty string indicates that no cursor is available. |
| `previous_cursor` | string | Cursor for the previous page. An empty string indicates that no cursor is available. |
| `limit` | integer | Page size applied to the response. |
| `request_id` | string | Request identifier for troubleshooting. |
