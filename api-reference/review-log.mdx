## Publication gate

The user approved publication of planned customer-facing Engage, Fax, Collect, Users, Webhooks, Integrations, and Reports endpoints. Publication is restricted by actual endpoint path rather than Basecamp group placement. Routes clearly associated with admin, callbacks, cron jobs, carriers, resellers, internal services, infrastructure, account plans, profiles, or unrelated product families remain marked `groups: ["internal"]` and are excluded from public navigation.

The current public set contains 355 captured endpoint pages. Additional placeholder resource overviews remain visible where Basecamp did not contain a supported method-bearing contract for that resource.
