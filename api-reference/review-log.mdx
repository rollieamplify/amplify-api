## Publication gate

The `Customer API v1` Postman collection is now the publication allowlist. It contains 115 customer-facing requests across Authentication, Send Fax, Numbers, Receive Fax, OCR & NLP, Contacts, Labels, Custom Field, Automations, Customer eSign Documents, and Customer eSign Templates. All other captured endpoint files remain available internally but are excluded from public navigation.

The public navigation currently references 102 existing endpoint pages that map to the approved collection. Thirteen approved Postman requests do not yet have a one-to-one Mintlify page or conflict with an older method/path contract; they should be authored or reconciled from the Postman request details before being added publicly. The known gaps are concentrated in Fax Report, several customer-specific Fax/Label/Custom Field operations, Numbers variants, Contacts detail/delete operations, and customer Automation routes.
