The Webhooks resource lets you register HTTPS endpoints that Amplify will call with a `POST` request each time a subscribed event occurs — such as a fax being delivered, a signature being completed, or an inbound message arriving. Each webhook has a `signing_secret` you use to verify that requests genuinely originate from Amplify. Manage which events each endpoint receives by updating the `events` array on the webhook.

<Note>
  The full interactive reference for this resource is generated from the Amplify OpenAPI spec. The endpoints and parameters below reflect the current public API surface.
</Note>

<Warning>
  The `signing_secret` returned when you create a webhook is shown **only once**. Copy it to a secure location immediately — it cannot be retrieved again. If you lose it, delete the webhook and create a new one.
</Warning>

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/v1/webhooks` | Create a webhook |
| `GET` | `/v1/webhooks` | List webhooks |
| `GET` | `/v1/webhooks/{id}` | Get a webhook |
| `PATCH` | `/v1/webhooks/{id}` | Update a webhook |
| `DELETE` | `/v1/webhooks/{id}` | Delete a webhook |

## POST /v1/webhooks

Register a new webhook endpoint. Amplify immediately sends a verification ping to confirm your endpoint is reachable. Subscribe to one or more event types by listing them in the `events` array.

### Request body

<ParamField body="url" type="string" required>
  The HTTPS URL of the endpoint to receive webhook events. Must use `https://` — HTTP endpoints are rejected.
</ParamField>

<ParamField body="events" type="array" required>
  Array of event type strings this webhook should subscribe to.

  <Expandable title="Available event types">
    | Event | Description |
    |-------|-------------|
    | `fax.delivered` | An outbound fax was delivered successfully |
    | `fax.failed` | An outbound fax failed to deliver |
    | `fax.received` | An inbound fax was received |
    | `message.delivered` | An outbound message was delivered |
    | `message.failed` | An outbound message failed |
    | `message.received` | An inbound message was received |
    | `call.completed` | A voice call ended |
    | `call.failed` | A voice call failed |
    | `esign.completed` | All signers have signed a document |
    | `esign.declined` | A recipient declined to sign |
    | `esign.viewed` | A recipient opened the signing link |
    | `form.extraction.completed` | A document extraction finished |
  </Expandable>
</ParamField>

### Code example

<CodeGroup>

```bash cURL
curl -X POST https://api.amplify.xyz/v1/webhooks \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/webhooks/amplify",
    "events": ["fax.delivered", "fax.received", "esign.completed"]
  }'
```

```javascript Node.js
const response = await fetch("https://api.amplify.xyz/v1/webhooks", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://example.com/webhooks/amplify",
    events: ["fax.delivered", "fax.received", "esign.completed"],
  }),
});

const { data } = await response.json();
// Store data.signing_secret securely — it is only shown once
console.log(data.signing_secret);
```

</CodeGroup>

## GET /v1/webhooks/{id}

Retrieve the full configuration for a single webhook endpoint.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the webhook.
</ParamField>

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the webhook, prefixed with `wh_`.
</ResponseField>

<ResponseField name="url" type="string">
  The HTTPS endpoint URL that receives event payloads.
</ResponseField>

<ResponseField name="events" type="array">
  Array of subscribed event type strings.
</ResponseField>

<ResponseField name="signing_secret" type="string">
  The webhook signing secret. This value is **only returned in the response to the original `POST /v1/webhooks` creation request**. All subsequent reads return `null` for this field.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the webhook was registered.
</ResponseField>

### Example response

```json
{
  "data": {
```

## PATCH /v1/webhooks/{id}

Update the URL or subscribed event types for an existing webhook. Replace the entire `events` array with each update.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the webhook to update.
</ParamField>

### Request body

<ParamField body="url" type="string">
  New HTTPS URL for the webhook endpoint.
</ParamField>

<ParamField body="events" type="array">
  Replacement array of event type strings. This replaces the existing subscription list entirely.
</ParamField>

## DELETE /v1/webhooks/{id}

Delete a webhook endpoint. Amplify immediately stops sending events to the registered URL. This action cannot be undone.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the webhook to delete.
</ParamField>

## Verifying webhook signatures

Amplify signs every webhook request with an HMAC-SHA256 signature computed from the raw request body using your `signing_secret`. Verify the signature before processing any event payload.

<CodeGroup>

```javascript Node.js
import crypto from "crypto";

function verifyWebhookSignature(rawBody, signatureHeader, signingSecret) {
  const expectedSignature = crypto
    .createHmac("sha256", signingSecret)
    .update(rawBody)
    .digest("hex");

  const trusted = Buffer.from(`sha256=${expectedSignature}`, "utf8");
  const received = Buffer.from(signatureHeader, "utf8");

  return crypto.timingSafeEqual(trusted, received);
}
```

```python Python
import hmac
import hashlib

def verify_webhook_signature(raw_body: bytes, signature_header: str, signing_secret: str) -> bool:
    expected = hmac.new(
        signing_secret.encode("utf-8"),
        raw_body,
        hashlib.sha256,
    ).hexdigest()
    trusted = f"sha256={expected}"
    return hmac.compare_digest(trusted, signature_header)
```

</CodeGroup>

<Warning>
  Always verify the webhook signature before acting on an event payload. Failing to do so leaves your endpoint open to spoofed requests.
</Warning>
