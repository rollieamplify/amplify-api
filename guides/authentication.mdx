---
title: "Authentication"
description: "Authenticate Amplify API requests with an access token or bearer token."
---

The Amplify API supports two authentication methods. Send one credential with every request.

## Access token

Send your Amplify access token in the `access_token` header.

```bash
curl "https://api.amplify.xyz/v1/numbers" \
  --header "access_token: $AMPLIFY_ACCESS_TOKEN"
```

## Bearer token

Send a JWT bearer token in the `Authorization` header.

```bash
curl "https://api.amplify.xyz/v1/numbers" \
  --header "Authorization: Bearer $AMPLIFY_ACCESS_TOKEN"
```

<Warning>
  Treat credentials like passwords. Store them in a secrets manager or environment variable and rotate them if they are exposed.
</Warning>

## Authentication errors

The API returns `401 Unauthorized` when authentication is missing or invalid. A valid credential can still receive `403 Forbidden` when it does not have permission to perform an operation.
