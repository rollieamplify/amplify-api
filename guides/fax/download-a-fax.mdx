Once a fax has been delivered or received, you can download its content as a PDF through the Amplify API. This is useful for archiving documents, triggering downstream processing, or surfacing fax content inside your application.

## Prerequisites

Before downloading, confirm that:

- You have the fax `id` (returned when sending, or provided in a `fax.received` / `fax.delivered` webhook payload)
- The fax status is either `delivered` (for outbound faxes) or `received` (for inbound faxes)

Attempting to download a fax that is still in `queued` or `sending` status will return a `409 Conflict` response. Check the status first if you are unsure — see [Track Fax Status](/guides/fax/track-fax-status).

## Download the fax

Make a `GET` request to `/v1/faxes/{id}/download`. Amplify responds with the fax document as binary PDF data with the `Content-Type: application/pdf` header.

<CodeGroup>

```bash cURL
curl --request GET \
  --url https://api.amplify.xyz/v1/faxes/fax_01hx.../download \
  --header 'access_token: YOUR_ACCESS_TOKEN' \
  --output fax_document.pdf
```

```javascript Node.js
import fs from "fs";

const faxId = "fax_01hx...";

const response = await fetch(
  `https://api.amplify.xyz/v1/faxes/${faxId}/download`,
  {
    headers: { access_token: "YOUR_ACCESS_TOKEN" },
  }
);

if (!response.ok) {
  throw new Error(`Download failed: ${response.status}`);
}

const buffer = await response.arrayBuffer();
fs.writeFileSync("fax_document.pdf", Buffer.from(buffer));
console.log("Fax saved to fax_document.pdf");
```

```python Python
import requests

fax_id = "fax_01hx..."

response = requests.get(
    f"https://api.amplify.xyz/v1/faxes/{fax_id}/download",
    headers={"access_token": "YOUR_ACCESS_TOKEN"},
)

response.raise_for_status()

with open("fax_document.pdf", "wb") as f:
    f.write(response.content)

print("Fax saved to fax_document.pdf")
```

</CodeGroup>

## Response details

A successful download returns:

- **HTTP status**: `200 OK`
- **Content-Type**: `application/pdf`
- **Body**: Raw binary PDF content

There is no JSON envelope — the response body is the file itself. Write the raw bytes directly to disk or stream them to your storage backend.

<Note>
  Always download fax documents using the `/v1/faxes/{id}/download` endpoint with your access token. Do not cache or bookmark the `download_url` field returned in webhook payloads — those URLs are time-limited and will expire. The API endpoint always returns the current, valid document for as long as the fax record exists in your account.
</Note>

## Save to cloud storage

If you want to store fax documents in cloud object storage rather than locally, stream the API response body directly to your storage client instead of writing to disk. Most cloud storage SDKs (AWS S3, Google Cloud Storage, Azure Blob Storage) accept a readable stream as the upload source, which avoids buffering the entire file in memory.

<Tip>
  For high-volume fax processing, consider triggering downloads asynchronously from a `fax.received` or `fax.delivered` webhook event and pushing the document to your storage pipeline immediately on arrival.
</Tip>
