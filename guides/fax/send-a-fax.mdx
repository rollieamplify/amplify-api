Use the Fax API to send PDF documents from your server to a destination fax number. Send requests as `application/json`.

## Prerequisites

Before sending a fax:

- Obtain a Bearer access token through the [authentication flow](/guides/authentication).
- Prepare the destination fax number and caller ID in [E.164 format](/guides/data-formats#phone-numbers), such as `+12509997881`.
- Prepare the PDF as [Base64-encoded document data or a publicly accessible document URL](/guides/data-formats#pdf-documents).

## Send a document

<Steps>
  <Step title="Choose a document source">
    Provide documents as objects in the `fax_data` array. Use `file_url` for a publicly accessible PDF URL or `file_data` for the complete PDF encoded as a Base64 string. Provide the PDF filename in `file_name`.
  </Step>

  <Step title="Build the JSON request">
    The following example sends a PDF by URL:

    ```bash
    curl --request POST "https://api.amplify.xyz/v1/faxes/send" \
      --header "Authorization: Bearer $AMPLIFY_ACCESS_TOKEN" \
      --header "Content-Type: application/json" \
      --data '{
        "fax_number": "<string>",
        "fax_data": [
          {
            "file_name": "document.pdf",
            "file_url": "https://example.com/document.pdf"
          }
        ]
      }'
    ```
  </Step>

  <Step title="Submit the request">
    Send the request from a server-side application. Do not expose the Bearer access token in browser or mobile-client code.
  </Step>
</Steps>

## Schedule a fax

Include `scheduled_date` to schedule the transmission. Use an [ISO 8601 timestamp](/guides/data-formats#dates-and-timestamps):

```text
2026-05-06T09:42:00Z
```

## Choose the fax quality

Set `fax_quality` to `low`, `standard`, or `hd`. If omitted, the selected Fax Default determines the quality. Without `template_id`, the account's default Fax Default is used.

## Apply a template

Use `template_id` for a Fax Default cover-page template or `smart_document_id` for a Smart Template. You cannot provide both fields in the same request, and `fax_data` remains required.

Find these IDs in the Amplify dashboard:

- **Settings → iFax Settings → Fax Defaults** for `template_id`
- **Settings → iFax Settings → Smart Templates** for `smart_document_id`

## Set priority and approval

Set `fax_priority` to `high` or `regular`. When omitted, it defaults to `regular`.

Set `is_required_approval` to the JSON boolean `true` or `false`.

## Other supported fields

The customer collection also includes:

- `caller_id`
- `template_id`
- `is_required_approval`
- `smart_document_id`

See [Send a fax](/api-reference/fax/post-fax-send) for the complete request schema.
