Amplify is a unified communications and document automation platform designed for developers who need to add fax, eSignature, messaging, voice, document generation, and phone number management to their products without juggling a dozen different providers. Every capability is accessible through a single REST API with consistent authentication, predictable response shapes, and shared webhooks — so you spend less time on integration plumbing and more time building.

## Who Amplify Is For

Amplify is built for product teams and backend engineers who need reliable, programmable communications infrastructure. It fits equally well in healthcare platforms sending secure faxes, legal-tech products collecting eSignatures, logistics apps sending SMS updates, or any workflow that touches regulated document exchange. If your product needs to communicate with the outside world — or automate paperwork — Amplify has an endpoint for it.

## API Versioning

The current stable version of the Amplify API is **v1**. All endpoints are prefixed with `https://api.amplify.xyz/v1`. Amplify follows a versioned release model — breaking changes will always be introduced under a new version prefix, and prior versions remain available for a minimum deprecation window with advance notice.

<Note>
  Always pin your integration to a specific version prefix (e.g., `/v1/`) so that future version releases don't affect your existing code unexpectedly.
</Note>
