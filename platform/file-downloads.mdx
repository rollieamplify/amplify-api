The Amplify API returns binary file content for several resource types, including delivered fax documents, completed e-signature documents, and call recordings. To download a file, make an authenticated `GET` request to the appropriate download endpoint. The API responds with the raw binary content and a `Content-Type` header indicating the file format.

## How Downloads Work

Download endpoints follow the same authentication pattern as all other Amplify API requests — include your access token in the `access_token` header. The response body is the raw binary file, not a JSON envelope. You stream or buffer this content and write it to disk or pass it downstream.

The API sets appropriate `Content-Disposition` and `Content-Type` headers on download responses so HTTP clients and browsers can handle the file correctly.

## Download Endpoints

| Resource | Endpoint | Description |
|---|---|---|
| Fax document | `GET /v1/faxes/{id}/download` | Download the PDF of a sent or received fax. |
| E-sign document | `GET /v1/esign/documents/{id}/download` | Download the completed, signed PDF document. |
| Call recording | `GET /v1/calls/{id}/recordings/{recording_id}/download` | Download the audio recording of a call. |

## Content-Type Headers

The `Content-Type` header in the download response tells you the file format:

| File Type | Content-Type |
|---|---|
| PDF document | `application/pdf` |
| MP3 audio recording | `audio/mpeg` |
| WAV audio recording | `audio/wav` |
| TIFF image | `image/tiff` |

## Download a File

The following examples show how to download a fax document and save it to disk:

<CodeGroup>

```bash curl
curl https://api.amplify.xyz/v1/faxes/fax_01hx.../download \
  -H "access_token: YOUR_ACCESS_TOKEN" \
  --output fax_document.pdf
```

```javascript Node.js
import fetch from "node-fetch";
import fs from "fs";
import { pipeline } from "stream/promises";

async function downloadFax(faxId, outputPath) {
  const response = await fetch(
    `https://api.amplify.xyz/v1/faxes/${faxId}/download`,
    {
      headers: {
        access_token: process.env.AMPLIFY_ACCESS_TOKEN,
      },
    }
  );

  if (!response.ok) {
    const error = await response.json();
    throw new Error(`Download failed: ${error.error.message}`);
  }

  // Stream the response body directly to disk to avoid loading the
  // entire file into memory
  const fileStream = fs.createWriteStream(outputPath);
  await pipeline(response.body, fileStream);

  console.log(`Saved to ${outputPath}`);
}

await downloadFax("fax_01hx...", "./fax_document.pdf");
```

</CodeGroup>

<Note>
Always download files through the API endpoint rather than caching or hardcoding download URLs. Amplify may rotate internal storage URLs at any time, and cached URLs may expire without notice. The API endpoints shown above are stable and will always resolve to the correct file as long as the resource exists.
</Note>

<Tip>
For large files such as long call recordings, stream the response body rather than buffering it entirely in memory. The Node.js example above uses `pipeline` to pipe the response stream directly to a write stream on disk — this keeps your application's memory footprint constant regardless of file size. Most HTTP client libraries provide a similar streaming interface.
</Tip>
