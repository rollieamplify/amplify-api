Amplify emits webhook events across four product areas: fax, eSign, messaging, and calls. You can subscribe to individual event types or to all events within a product group. This page describes every available event type and shows an example payload for each product area so you know exactly what data to expect in your handler.

## Fax Events

These events fire at each stage of an outbound fax transmission, and whenever an inbound fax is received on one of your numbers.

| Event | Description |
|---|---|
| `fax.queued` | The fax has been accepted and queued for sending |
| `fax.sending` | Transmission to the receiving fax machine has started |
| `fax.delivered` | The fax was successfully received by the destination |
| `fax.failed` | The fax could not be delivered after all retry attempts |
| `fax.received` | An inbound fax was received on one of your Amplify numbers |

## eSign Events

These events track the lifecycle of a signature request from the moment a document is sent to a recipient through completion, declination, or expiry.

| Event | Description |
|---|---|
| `esign.sent` | The signature request was sent to the recipient |
| `esign.viewed` | The recipient opened the document |
| `esign.completed` | All required signers have signed the document |
| `esign.declined` | A signer chose to decline the request |
| `esign.expired` | The signing deadline passed before all signers completed |

## Messaging Events

These events cover the full lifecycle of an outbound message and fire in real time when an inbound message arrives on your number.

| Event | Description |
|---|---|
| `message.sent` | The outbound message was accepted and sent |
| `message.delivered` | The carrier confirmed delivery to the recipient's device |
| `message.failed` | The message could not be delivered |
| `message.received` | An inbound message was received on one of your Amplify numbers |

## Call Events

These events track the state of outbound and inbound calls, and fire a separate event when a call recording becomes available for download.

| Event | Description |
|---|---|
| `call.initiated` | An outbound call has been initiated |
| `call.answered` | The call was answered by the recipient |
| `call.completed` | The call ended normally |
| `call.failed` | The call could not be connected |
| `call.recording_available` | A call recording has finished processing and is ready to download |

<Info>

</Info>
