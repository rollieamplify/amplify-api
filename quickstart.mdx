## Prerequisites

Before you begin, you need:

- An Amplify account with API access
- An Amplify access token or bearer token
- A command-line HTTP client such as `curl`

<Warning>
  Keep credentials secret. Never expose an access token or bearer token in browser code, public repositories, or client-side applications.
</Warning>

<Steps>
  <Step title="Set your credential">
    Store your access token in an environment variable so it does not appear directly in your command history.

    ```bash
    export AMPLIFY_ACCESS_TOKEN="your_access_token"
    ```
  </Step>

  <Step title="Make a request">
    Retrieve a list of phone numbers from the production API.

    ```bash
    curl "https://api.amplify.xyz/v1/numbers?limit=10" \
      --header "access_token: $AMPLIFY_ACCESS_TOKEN" \
      --header "Accept: application/json"
    ```

  </Step>

  <Step title="Inspect the response">
    A successful list response contains a `data` array and pagination metadata.

    ```json
    {
      "data": [],
      "meta": {
        "total": 0,
        "next_cursor": "",
        "previous_cursor": "",
        "limit": 10,
        "request_id": "9b16f7a0-fdb4-457a-8cad-fa158c71cf78"
      }
    }
    ```
  </Step>
</Steps>

<Tip>
  Save the `meta.request_id` value when troubleshooting a request.
</Tip>
