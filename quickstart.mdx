This guide walks you through making your first successful call to the Amplify API in under five minutes. You'll generate an API key, send a request to list faxes, and read the response — all from your terminal or preferred HTTP client. No SDK or special tooling required.

<Note>
  Keep your API key secret at all times. Never hard-code it in source files you commit to version control or expose it in client-side code. Use environment variables or a secrets manager instead.
</Note>

<Steps>
  <Step title="Get your API key">
    Log in to the Amplify dashboard at [https://app.amplify.xyz](https://app.amplify.xyz). Navigate to **Settings → API Keys** and click **Create API Key**. Give the key a descriptive name (for example, `my-first-integration`) and click **Generate**.

    Copy the key immediately — it will only be shown once in full. Your key follows this format:

    ```text
    ak_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    ```

    Store it in an environment variable so you can reference it in the examples below:

    ```bash
    export AMPLIFY_API_KEY="ak_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
    ```
  </Step>

  <Step title="Make your first request">
    Send a `GET` request to `/v1/faxes` to retrieve your fax list. This is the simplest way to confirm your key is valid and your connection to the API is working.

    <CodeGroup>
      ```bash curl
      curl https://api.amplify.xyz/v1/faxes \
        -H "Authorization: Bearer $AMPLIFY_API_KEY"
      ```

      ```python Python
      import os
      import requests

      api_key = os.environ["AMPLIFY_API_KEY"]

      response = requests.get(
          "https://api.amplify.xyz/v1/faxes",
          headers={"Authorization": f"Bearer {api_key}"}
      )
      print(response.json())
      ```

      ```javascript Node.js
      const apiKey = process.env.AMPLIFY_API_KEY;

      const response = await fetch("https://api.amplify.xyz/v1/faxes", {
        headers: { "Authorization": `Bearer ${apiKey}` }
      });
      const data = await response.json();
      console.log(data);
      ```
    </CodeGroup>

    <Tip>
      If your account is in test mode, all API calls operate against a sandboxed environment — no real faxes are sent and no charges are incurred. Look for a **Test Mode** toggle in the dashboard under Settings.
    </Tip>
  </Step>

  <Step title="Read the response">
    A successful request returns an HTTP `200 OK` with a JSON body containing a paginated list of faxes. If your account is new, the `data` array will be empty — that's expected.

    ```json
    {
      "data": [
        {
          "id": "fax_01hx4k9mzq3r7vbn2cwtpdjfe8",
          "status": "delivered",
          "to": "+15551234567",
          "from": "+15557654321",
          "pages": 2,
          "created_at": "2024-01-15T10:30:00Z",
          "completed_at": "2024-01-15T10:31:45Z"
        }
      ],
      "meta": {
        "total": 1,
        "page": 1,
        "per_page": 20
      }
    }
    ```

    If you receive an HTTP `401 Unauthorized`, double-check that you included the `Authorization` header and that your key is correct. See the [Authentication guide](/authentication) for details on error responses.
  </Step>
